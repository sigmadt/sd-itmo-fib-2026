# Карточка-подсказка

Сегодня ищем то, что делает дорогим изменение кода. Стиль, именование и форматирование не ищем.

## Принципы SOLID

| Название | Как узнать |
|---|---|
| SRP | У класса несколько причин меняться |
| OCP | Новое поведение добавляется только правкой старого кода |
| LSP | Наследник ведет себя так, что код, работающий с базовым классом, ломается |
| ISP | Интерфейс заставляет реализовывать ненужные методы |
| DIP | Высокоуровневый код напрямую создает или вызывает низкоуровневые детали (файлы, консоль, процессы) |

## Code smells

| Название | Как узнать |
|---|---|
| God Object | Один класс знает и делает почти все |
| Long Method | Метод не помещается на экран и делает несколько разных вещей |
| Duplicated Code | Одна логика в нескольких местах |
| Shotgun Surgery | Одно изменение требует правок во многих местах |
| Switch Statements | Длинная цепочка if/switch по типу или имени |
| Primitive Obsession | Строки и числа вместо маленьких типов |
| Global Data | Изменяемое состояние, доступное отовсюду |
| Dead Code / Speculative Generality | Код, который не вызывается или сделан «на будущее» |
| Refused Bequest | Наследник отказывается от части унаследованного |
